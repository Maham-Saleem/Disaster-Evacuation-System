#Disaster Alert and Evacuation System

A smart disaster management system designed to assist in safe evacuation during emergencies such as floods, earthquakes, fires, and other natural disasters.

##Features

Emergency evacuation guidance
User-friendly interface
Safe route recommendations

##Technologies Used

C++
Object-Oriented Programming (OOP)
File Handling
Data Structures
APIs 

##Purpose of the Project

The purpose of this project is to improve emergency response and public safety by helping users receive evacuation instructions during disaster situations.

##How the System Works

The safe locations are saved in the system.
The user then enters his/her location.
The system calculates the safest and most fastest route to the nearby safe location using Map API and Graphs.
Evacuation routes and safety instructions are displayed.

##Advantages

Helps reduce panic during emergencies
Provides quick access to safety information
Supports organized evacuation planning
